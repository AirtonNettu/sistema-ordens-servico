## Convenções
- `RF-001`: requisito funcional — comportamento que o sistema deve oferecer.
- `RNF-001`: requisito não funcional — atributo de qualidade ou restrição verificável.
- Estados: **proposto**, **validado**, **alterado** ou **descartado**.
- Cada requisito deve ter origem, descrição inequívoca, prioridade e critério de aceitação verificável.
